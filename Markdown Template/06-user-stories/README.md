# User Story Map

The user stories of ELIZA: features divided into epics, epics into stories and stories into tasks, with story points estimated with planning poker. The backlog is kept in Jira (project KAN); these pages show it as of each version's date.

## Versions

- [User Story Map v1](01-user-story-map-v1.md): end of Sprint 1 (27/10/2026), latest version
- [User Story Map v2](02-user-story-map-v2.md): end of Sprint 2 (18/11/2026), with the final user stories, a test for each story and the estimated backlog
