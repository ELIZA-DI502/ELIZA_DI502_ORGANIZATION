# User Story Map

The user stories of ELIZA: features divided into epics, epics into user stories and tasks, and those into sub-tasks, with points estimated with planning poker. The backlog is kept in Jira (project KAN); these pages show it as of each version's date.

## Versions

- [User Story Map v1](01-user-story-map-v1.md): end of Sprint 1 (27/10/2026)
- [User Story Map v2](02-user-story-map-v2.md): Sprint 2 (08/11/2026), latest version: the backlog after the Sprint 1 review, with test cases for every current user story, written in Sprint 2 under [KAN-114](https://yarengursoy.atlassian.net/browse/KAN-114)
